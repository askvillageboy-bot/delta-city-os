# Delta City OS

**Warri Pilot — Digital Twin & Smart City OS**

## Session Log
- 0–6: Map, markets, live markers, fixed quests
- 7–8: Promo offers + claims (+ Supabase-ready)
- **9: Civic Quests** — Keep Warri Clean + Corridor Watch

## What you see now
- Green = markets
- Gold = active vendor offers
- Red = dumpster points (full = needs attention)
- Orange line = sweeping corridor
- Blue / purple = Street Keepers / BYKA

**Civic Actions** in the panel let users complete clean-city quests and earn points + badges (stored locally for the demo).

## Quick Start
```bash
npm install
npm run dev
```
